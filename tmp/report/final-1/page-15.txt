3.3 Database Tables
Tables 3.1–3.4 describe the actual SQLAlchemy model columns. VARCHAR lengths are shown 
as String lengths in the model. Integer identifiers are surrogate primary keys. The profile user_id 
columns are unique foreign keys, so a user cannot have duplicate records in the same profile table.
